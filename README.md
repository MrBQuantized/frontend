# Frontend Learning Repository

A personal collection of frontend practice exercises and experiments covering the fundamentals of web development — from HTML/CSS and vanilla JavaScript to TypeScript.

## 📁 Repository Structure

```
.
├── css/            # CSS practice & styling exercises
├── html/           # HTML structure & semantic markup practice
├── javascript/     # Vanilla JavaScript exercises & experiments
├── typescript/     # TypeScript exercises & projects
├── .vscode/        # Editor configuration
├── package.json    # Project metadata / dependencies
├── .gitignore
└── README.md
```

## 🎯 Purpose

This repo serves as a learning playground and reference for frontend development. Each folder contains focused practice work that builds on core web technologies.

## 🛠️ Technologies

- **HTML5** — semantic markup & accessibility
- **CSS3** — layouts, responsive design, animations
- **JavaScript** — DOM manipulation, ES6+, async patterns
- **TypeScript** — typed JavaScript & safer code
- **VS Code** — primary editor (config included in `.vscode/`)

## 🚀 Getting Started

Clone the repository:

```bash
git clone <your-repo-url>
cd <repo-name>
```

Most folders contain plain HTML/CSS/JS files that can be opened directly in a browser. Navigate into any folder and open the relevant `.html` file to view it.

> Check each folder for specific instructions if needed.

## 📦 Dependencies

Root-level dependencies are defined in `package.json`. If needed:

```bash
npm install
```
