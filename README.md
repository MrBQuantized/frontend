# Frontend Learning Repository

A personal collection of frontend practice projects, exercises, and experiments covering the fundamentals of web development — from HTML/CSS and vanilla JavaScript to TypeScript, React, and a personal portfolio.

## 📁 Repository Structure

```
.
├── css/            # CSS practice & styling exercises
├── html/           # HTML structure & semantic markup practice
├── javascript/     # Vanilla JavaScript exercises & experiments
├── mini_project/   # Small standalone projects for practice
├── portfolio/      # Personal portfolio site
├── react-app/      # React application(s)
├── typescript/     # TypeScript exercises & projects
├── .vscode/        # Editor configuration
├── package.json    # Project metadata / dependencies
└── .gitignore
```

## 🎯 Purpose

This repo serves as a learning playground and reference for frontend development. Each folder contains focused practice work that builds on core web technologies and modern tooling.

## 🛠️ Technologies

- **HTML5** — semantic markup & accessibility
- **CSS3** — layouts, responsive design, animations
- **JavaScript** — DOM manipulation, ES6+, async patterns
- **TypeScript** — typed JavaScript & safer code
- **React** — component-based UI development
- **VS Code** — primary editor (config included in `.vscode/`)

## 🚀 Getting Started

Clone the repository:

```bash
git clone <your-repo-url>
cd <repo-name>
```

### Running individual projects

Most folders contain plain HTML/CSS/JS files that can be opened directly in a browser. For the React app:

```bash
cd react-app
npm install
npm start
```

> Check each project folder for its own `README` or config file for specific instructions.

## 📦 Dependencies

Root-level dependencies are defined in `package.json`. If needed:

```bash
npm install
```
